# Real-Time Hybrid Blockchain Market Indicator (BTC)

A real-time Bitcoin (BTC) market indicator integrated with TradingView.
Built as my BS Information Technology Final Year Project at the University of Sialkot.

## Features
- Anchored VWAP
- Fibonacci levels
- Support and Resistance zones
- Order Blocks
- Points of Interest (POI)
- RSI

## Technologies
- [Python, Pinescript, Discord, TradingView, APIs]

## How It Works:
Combines seven technical-analysis modules into a single indicator. 
Analyzes multiple technical factors simultaneously and displays the resulting technical information directly on the TradingView chart. 
Helps the trader view different market factors within one analysis environment. 
The modules can work together without interfering with each other. 
Seven Integrated Modules
POI + Support & Resistance + Order Blocks + RSI + EMA + Fibonacci + Anchored VWAP
